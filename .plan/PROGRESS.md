- 2026-08-14 — `detail-infra`. Resolved all six items `detail-architecture` flagged. **Redis gets AOF persistence** — not for sessions but for the job queue, since a user whose 2 GB extraction vanished on a Redis restart sees it stuck at `queued` forever with no way to know it's dead. The four scheduled tasks (reconciliation sweep, hourly metering, backend health, audit retention) are **in-process tickers rather than systemd timers**, preserving the one-binary story — with the single-instance assumption that creates recorded rather than left to be discovered. systemd unit `Requires=` Mongo and Redis (failing at boot beats serving 500s) and caps memory, because extraction runs in-process and an unbounded worker takes MongoDB down with it. Resolved **PRD Q3**: offline `--rotate-credential-key` with both keys supplied, rehearsed on staging. Added a **backups** position the defaults don't cover: Mongo is the only irreplaceable state, and a restore must be paired with reconciliation since metadata and bytes are separately stored. Noted that desktop CI is the one place this project pays GitHub for minutes.
