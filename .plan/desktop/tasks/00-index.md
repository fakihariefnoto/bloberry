## Screen content — owned elsewhere

Desktop owns **no screens**. Screen content is `web/mockup/`'s desktop-width wireframes (loaded unchanged), so all screen-content tasks live in `web/tasks/` (generated by `build-web`, 35 files). This folder covers only what's genuinely desktop-specific — the shell, chrome deltas, packaging. **No cross-screen flows file** (desktop has no screens; feature cohesion is owned by `web/tasks/33-flows.md`).

## Dependency edges

- **`01-framework-setup` blocks everything** in this folder.
- **`02-window-shell` depends on `web/tasks/01-setup.md` + the web build** (the shell loads `web/dist`).
- **`03-chrome-mockups` depends on `02`** (the deltas render inside the shell).
- **Packaging files depend on `02`** (the binary must exist) and on `web/tasks/` (the dist it embeds).
- **`07-auto-update` depends on `04`** (signing; on Linux on `06`).
- **`08-release-ci` depends on all packaging files.**

## External edges (from `architecture.md` §7) — the load-bearing ones

- **`01-framework-setup` Depends on `backend/tasks/01-setup.md` AND `web/tasks/01-setup.md`.**
- **Do NOT run `wails3 init` in this repo** (`desktop/README.md` — the module already exists). Wails is a **third binary inside the existing Go module** (`cmd/bloberry-desktop/`), Wails dependency added to the existing `go.mod`. This is the one place a desktop build usually fails (the standard scaffold-owner rule says Wails owns the init — that row doesn't apply to layout I).
- If a Wails template is wanted, `wails3 init` runs in a **scratch directory outside the repo** and is ported across by hand.
- **`web/dist` is consumed by both server and desktop** — build order is `openapi → web build → go build` (`architecture.md` §7 edge 3).
- **Wails v3 is Taskfile-driven** — pin the version and take commands from that release's Taskfiles (`desktop/README.md` §Packaging).

None. The packaging table is concrete per artifact with commands, config paths and prerequisites; signing decisions (required/deferred/none) are recorded; the CI exception (macOS/Windows billable runners) is explicit.
