# Task group — 04 core infra

**Depends on:** `01-setup.md`, `02-design-tokens.md`. **Blocks:** the API-touching screens + the auth screens' submit paths.

- [ ] **`build.yaml` snake_case** — `json_serializable` `field_rename: snake` globally (README's trap; verified before any model is built — a model with camelCase deserializes to all-null with no error).
- [ ] **`lib/api/` — generated Dart client** from `api/openapi.yaml` (PRD D8, `architecture.md` §7; generated by the backend's `make generate` — this task consumes it, doesn't hand-write it). Internal to the app in v1, not published.
- [ ] **Dio + envelope interceptor** — parse `{data?, messages?: [{code, content}]}` in **one** layer. `messages[].code` drives branching (`key_revoked` → re-login, `quota_exceeded` → link to `usage`); `messages[].content` → snackbar. Dio exceptions + stack traces `debugPrint`-only, never shown (guard rule 4).
- [ ] **Token storage** — `flutter_secure_storage` for access + refresh (never SharedPreferences); refresh wiring with platform-aware TTLs (mobile 720h/2160h).
- [ ] **`lib/store/`** — session state, current tenant, and the **persistent upload queue** (SQLite, not memory — survives app kill, PRD MB2).
- [ ] **`lib/validators.dart`** — email, password strength, folder name (no `/`, no leading dot, length cap), TTL range — centralized, never duplicated (README §Form validation). **No phone dial-code** (no phone input in this app).
- [ ] **Biometric/PIN unlock plumbing** — Settings toggle (off by default), `local_auth` prompt, PIN fallback. **`MainActivity` extends `FlutterFragmentActivity`** (not `FlutterActivity`) — the Android requirement that crashes the biometric prompt at runtime if missed. Failure path logged, not swallowed (guard rule 5). Set up as its own task, not buried.
- [ ] **Offline detection** — `connectivity_plus` so the queue shows "waiting for connection" rather than failing.

**tests:** envelope parse (data/messages/code-branching/unknown-code); snake_case round-trip (a model field populates, not null); secure-storage round-trip; queue survives a kill+relaunch; biometric failure path logs without crashing.
